# Slide 8: Shipped vs impact

Act: Delivery. Audiences: Leadership, Staff.

## The question it answers

Did we ship what we said, and did it work?

## Required data

The commitments made last period, each with one target metric named before launch.

| Source | What the slide reads | Required |
|---|---|---|
| Issue tracker | Last period's commitments, each with one target metric named before launch | Yes |
| Product analytics | The result for each target metric | Yes |

## Minimum evidence to render

At least one of these blocks, filled from computed data: `table`.
If the data is missing, put a `data_needed` block in its place with an owner and a due date. Never fill the gap with prose.

## The rule

Group by outcome. A shipped item with no metric goes under "no movement". Never list features without results.

## Time window

State the window on the slide's `asof` line. In the example: "Sources: Linear projects, release notes, product analytics. Q3 FY26."

## Titles

- Good: "We shipped 9 of 11 commitments. 5 have moved their target metric so far." (a claim someone can check).
- Bad: "Shipped vs impact" (a label; it claims nothing).
