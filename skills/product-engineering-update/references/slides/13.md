# Slide 13: AI in how we build

Act: Measurement. Audiences: Leadership.

## The question it answers

Is AI making us better, or only busier?

## Required data

Tool usage data, a pre-AI baseline, cost per engineer, the quality metrics from slide 9.

| Source | What the slide reads | Required |
|---|---|---|
| AI tool admin data | Usage and cost per engineer by tool | Yes |
| Source control and CI | A baseline from before the tools, and the quality metrics from slide 9 | Yes |
| Developer survey | Developer sentiment | No |

## Minimum evidence to render

At least one of these blocks, filled from computed data: `table`.
If the data is missing, put a `data_needed` block in its place with an owner and a due date. Never fill the gap with prose.

## The rule

Report utilization, effect and cost together. Split attended tools from unattended agents. Any effect needs a baseline and a window. Adoption is never a result.

## Time window

State the window on the slide's `asof` line. In the example: "Sources: AI tool admin data, GitHub, developer survey. Baseline is Q3 FY25."

## Titles

- Good: "88% of engineers use AI weekly and pull requests move 18% faster than a year ago. Reviews take 44% longer." (a claim someone can check).
- Bad: "AI in how we build" (a label; it claims nothing).

## Reading

- [METR's 2025 trial](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/) (Jul 2025, 16 developers, 246 issues) found experienced developers took 19% longer with AI. In [Feb 2026](https://metr.org/blog/2026-02-24-uplift-update/) METR called that result out of date and changed its experiment design.
- [Stripe, Minions](https://stripe.dev/blog/minions-stripes-one-shot-end-to-end-coding-agents) (2026). More than 1,300 merged pull requests a week with no human-written code, every one reviewed by a person.
- Ramp CPO Geoff Charles (Sep 2026) put agent-written pull requests at 75% and called speed a systems problem. A Ramp data engineer described internal AI return as measured by "vibes" ([dbt Summit 2026](https://www.getdbt.com/blog/ramp-internal-ai-agents-million-sessions)).
- [Vercel Ship 2026](https://vercel.com/blog/vercel-ship-2026-recap) (Oct 2026). Agents that find and fix bugs from production context.
- [Shopify's AI memo](https://www.digitalcommerce360.com/2025/04/08/internal-memo-shopify-ceo-declares-ai-non-optional/) (Apr 2025). The best-known example of an explicit AI stance, which DORA lists as a capability.
