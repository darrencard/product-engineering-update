# Slide 10: Platform & security

Act: Delivery. Audiences: Leadership.

## The question it answers

Is the base we build on safe, stable and getting simpler?

## Required data

Service-level objectives and error budgets, incident data, audit status, vulnerability ageing, the debt register.

| Source | What the slide reads | Required |
|---|---|---|
| Incidents and status | Availability objectives, error budgets and incident data | Yes |
| Security tracker | Audit status and vulnerability ageing | Yes |
| Documents | The architecture decision log and debt register | No |

## Minimum evidence to render

At least one of these blocks, filled from computed data: `cards`.
If the data is missing, put a `data_needed` block in its place with an owner and a due date. Never fill the gap with prose.

## The rule

Tie platform work to money or risk, such as lower cloud spend, faster enterprise onboarding or avoided downtime. Report objectives and error budget in place of raw uptime. State the engineering strategy in three lines. The board gets slide 9b.

## Time window

State the window on the slide's `asof` line. In the example: "Sources: status page, security tracker, architecture decision log. Q3 FY26."

## Titles

- Good: "Every service met its availability objective. SOC 2 Type II moved one quarter." (a claim someone can check).
- Bad: "Platform & security" (a label; it claims nothing).

## Reading

- [Will Larson, Steps to build an engineering strategy](https://lethain.com/components-of-eng-strategy/) (Mar 2025). Explore, diagnose, refine, set policy, then run it. Each step feeds the next.
- [InfoQ, Grafana applies SLOs and error budgets to AI agent behaviour](https://www.infoq.com/news/2026/10/grafana-slo-ai-agent/) (Oct 2026). Service-level objectives and error budgets can track agent quality, because a system can stay up while it becomes less trustworthy.
- [InfoQ on Joy Ebertz, All Tech Debt is Not Created Equal](https://www.infoq.com/news/2026/03/tech-debt-not-equal/) (QCon London, Mar 2026). Decide which debt matters with 6 questions, starting with the cost of doing nothing.
- [Product School, AI-native](https://productschool.com/blog/artificial-intelligence/ai-native) (Feb 2026). Version prompts and models, log behaviour, keep an incident process for AI features.
