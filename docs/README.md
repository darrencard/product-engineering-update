# Documentation

Reference for the Product & Engineering Update skill. Start with the [README](../README.md) for what it does and the one-prompt install.

| Doc | Read it when |
|---|---|
| [Validator rules](validator-rules.md) | A render is blocked, or you want to know what the validator checks before you write a slide. |
| [Connectors](connectors.md) | You want to know which systems the skill reads, what each reader needs, and which have run on a live account. |
| [Security and data handling](security.md) | You are reviewing the skill for your organisation: where data goes, the supply chain, prompt injection and the GitHub Action's permissions. |
| [Intake and CLI reference](intake-and-cli.md) | You are filling in `intake.json` by hand, or scripting a run. |
| [Troubleshooting](troubleshooting.md) | A script stopped with an error and you want the fix. |

Something wrong or missing? File a [friction report](https://github.com/darrencard/product-engineering-update/issues/new?template=friction.yml): what you tried, what you expected, what happened, and what would fix it. Agents running the skill draft these too, and file them only after you say yes.
